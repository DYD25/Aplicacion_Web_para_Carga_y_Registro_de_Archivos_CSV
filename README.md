# Aplicación Web para Carga y Registro de Archivos CSV

Esta es una aplicación desarrollada con **PHP**, **JavaScript**, **HTML** y **CSS** que permite a los usuarios:

- Subir archivos en formato `.csv`
- Validar su contenido
- Registrar automáticamente los datos en una base de datos **MySQL**

Está pensada para facilitar la carga masiva de información desde archivos estructurados, ideal para reportes, registros administrativos o sistemas escolares.

## 🚀 Tecnologías utilizadas

- **PHP 8.0.0 o superior** (obligatorio)
- JavaScript (nativo)
- HTML5 y CSS3
- MySQL
- Bootstrap (opcional, si lo estás usando)

## 📦 Funcionalidades

- Validación básica del archivo CSV (estructura y extensión)
- Visualización previa del contenido
- Inserción de los datos en tabla MySQL
- Mensajes de confirmación o error amigables

## ⚙️ Requisitos

- PHP **8.0.0 o superior**
- Servidor local (recomendado: [Laragon](https://laragon.org/), XAMPP o similar)
- MySQL activo
- Navegador moderno

## 📌 Nota importante

Esta aplicación **requiere PHP 8.0.0 o superior** para garantizar la compatibilidad con las funciones modernas utilizadas.
